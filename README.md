# 环城大富翁

一个轻量的人机大富翁小游戏。掷骰子、买地、升级、抽卡，在连锁收租、地产易主与意外翻盘中看一场小城好戏。新版强化微缩城市画面和事件演出，保留三张地图与两种游戏模式。

## 本地运行

需要通过 HTTP 服务器打开；页面使用 ES module，直接双击 `index.html` 无法完整加载。

在本项目目录打开终端，安装有 Python 时运行：

```powershell
python -m http.server 8876
```

浏览器打开 [http://localhost:8876](http://localhost:8876)。停止服务器可在终端按 `Ctrl+C`。

## 开始游戏或观看演出

首页选择地图，点击“好戏开场”，再选择模式进入正式对局。

| 地图 | 步位 | 回合上限 | 特点 |
| --- | ---: | ---: | --- |
| 经典环线 | 22 | 30 | 原有的均衡节奏 |
| 紧凑冲突 | 18 | 26 | 三街区短环，随机冲刺，更快形成连锁收租 |
| 都市大环线 | 28 | 40 | 六街区连续单环，随机开业地产，建设与翻盘更充分 |

- **回合制**：按所选地图的上限结算，现金最多者获胜。
- **破产淘汰制**：无力偿还过路费即破产，对手获胜。

| 地图 | 每人基础开局金 | 后手额外补给 | 经过起点补给 |
| --- | ---: | ---: | ---: |
| 经典环线 | ¥1,600 | ¥500 | ¥300 |
| 紧凑冲突 | ¥1,600 | ¥500 | ¥300 |
| 都市大环线 | ¥2,000 | ¥300 | ¥450 |

后手补给在硬币确定先后手时一次性发放，玩家和 AI 遵循同一规则。回合推进以回到本局先手为一轮，修复 AI 先手时玩家少一个基础轮次的问题；休整、护盾与额外行动仍各按原规则结算。补偿用于缓解抢地优势，不保证真人对局胜率恰好各半。

首页的“先看一场好戏”进入所选地图的独立示例，用示例地产和资金展示连锁收租、地标征用、护盾救场、绝境救助、买地开张、建筑升级及城市奇遇，不计入历史战绩。紧凑冲突和都市大环线还可体验冲刺路线。预览内每个按钮会重新设置示例局面。想实际游玩，请点击“开始正式对局”；正式对局中隐藏预览入口，避免误重置正在玩的游戏。

紧凑冲突的冲刺站随机前进 2–4 格，都市大环线的城市快线随机前进 3–5 格；均沿当前行进方向移动，并继续结算落点。两图的传送港随机跳到地产后，也会立即触发购买、升级或收租；传送不领取经过起点的奖励。护盾等原有规则照常生效。

银行存款会单独掷一次存款骰，点数 × 30 决定应存金额，最多扣除现有现金；这颗骰子不改变步数，也不触发掷六再动。满级收益地标把收入与“已满级”合在同一幕展示；救助金到账后，下一回合只提示休整，不重复播放救济演出。

都市大环线每局在六个街区各随机选一处无主地产，提前建好 Lv.1 建筑；仍按原地价出售，买下即保留建筑。不同开业组合让每局有不同的热门地段。28 个步位首尾相连，顺行和逆行都会经过全图；当前棋子带步位编号和下一步箭头。地图标题下可展开“本图玩法”，查看地图特性与本局开业地段。

大环线的回合制让救助带来脱困机会：每次无力付清租金时，照常获得 ¥200 救助金并休整一回合，同时获得一次过路护盾，免交接下来的一笔租金。护盾用后消失，帮助重新展开对局。经典、紧凑和破产淘汰制保留原来的救助或淘汰规则。

游戏页顶部可以分别开关音效和音乐。普通事件约停留 3 秒，一般租金约 4.5 秒，大额租金、反超、征用、护盾和救济约 6 秒，结算至少 6 秒；长文字会延长，最多 10 秒。点击“停住看”可暂停自动继续，再点“继续自动”恢复；“继续”始终立即进入下一步。演出响应系统的“减少动态效果”偏好；浏览器无法使用 WebGL 时会回退到原有棋盘。

机会广场改用七类城市奇遇：装修队免费加盖一层、整个街区免费升一级、获得一次过路护盾、专车随机送到地产并结算、双方交换位置、赞助公共金库，以及随全城建筑数量增长的双人夜市分红。只抽取当前能生效的事件；没有建筑可升级、已有护盾或双方同位时，会跳过相应事件。改造保留产权，可能让对手或无主地产的租金上涨；换位不立即结算新落点；专车不领取过起点补给。夜市金额明确为每人所得，赞助金额只进入公共金库。每种奇遇有成对喊话和已发生结果徽标，至少保留 5.2 秒。

点击地块后，可以通过信息面板的“近看建筑”旋转、缩放建筑，比较各级外观。购买或升级时也可点击“看看满级建筑”。切换等级保持同一取景，直观看到体量增长；关闭预览后回到当前对局，不花钱、不升级。

整张棋盘也支持互动：按住棋盘拖动旋转，滚轮缩放；触屏可单指转动、双指缩放。右上角提供转向、缩放与回正按钮。日常状态刷新保持你的镜头，新局恢复默认取景；拖动松手不会误选地块，事件演出和建筑近看期间暂停棋盘手势。

已购地产用完整的圆角产权框围住整块土地，玩家为青绿、对手为橙红；双格地产只有一个连续外框。选中或发生事件时另亮外侧轮廓，产权颜色保持可辨。

收租时付款方和收款方会用漫画气泡互相喊话，随大额账单、现金见底、反超、护盾和救助呈现不同反应。台词按整组轮换，对方稍晚接话；从小额拌嘴到大额破防，买地得瑟时对手也会回嘴。买地会播放开张庆祝，连成街区、购入大型地产或带楼入手时强化表现，徽标只展示实际购得的地产，费用仍按原价扣除。普通购买的双人对话保留约 4.5 秒，重要购买约 6 秒；台词和粒子使用独立的表现序列，不参与掷骰或机会事件的随机抽取。

小城增加白天、黄昏、夜晚与自动光照，夜间窗灯、路灯逐渐亮起。中央喷泉的水流与涟漪、散步的小人、热气球和点状微光让城市保持生气；机会广场转盘、城建局吊索摆锤使用独立部件围绕真实轴心运动。系统选择“减少动态效果”时保留静态场景和事件台词，页面隐藏时暂停环境动画。

## 代码与美术入口

- `game.js`：地图、回合、资金、地产、卡牌和胜负规则。
- `scene.js`：Three.js 微缩城市、建筑模型、棋子、灯光与场景动画。
- `scene-life.js`：昼夜光照、中央生活场景、特殊建筑活动部件与环境粒子。
- `presentation.js`：连接游戏状态与表现层，更新信息面板，组织事件演出和独立预览。
- `drama.js`：收租、征用、护盾等事件的画面、节奏与音效反馈。
- `index.html`、`presentation.css`：页面结构和新版界面样式；`styles.css` 保留原棋盘回退样式，`scene.css` 与 `drama.css` 分别配合城市和演出。

城市资产由真实 Blender 建模生成。基础库保留 20 个模型；第二轮增加 9 个分级地标与 8 个特殊地块模型。摩天楼使用真实增长的细长塔身和金色冠顶；金融中心是错落双塔；温泉庄园由多栋楼阁、汤池、瀑布、拱桥与庭院组成。特殊地块通过穹顶、圆形金库门、塔吊、巨牌、转盘和门架等不同轮廓识别。

- `assets/models/city-kit.glb`：游戏加载的模型库，约 2.9 MB。
- `assets/models/city-kit.blend`：可编辑的 Blender 模型库，含预览相机与灯光。
- `art/build_city_kit.py`：完整建模与导出脚本。
- `assets/models/landmarks.glb`、`landmarks.blend`：摩天楼、金融中心、温泉庄园的三级模型与可编辑源文件。
- `assets/models/specials.glb`、`specials.blend`：八种特殊地块与可编辑源文件。
- `art/build_landmarks.py`、`art/build_specials.py`：第二轮建模与导出脚本。
- `art/build_scene_life.py`、`assets/models/life-specials.glb`、`life-specials.blend`：沿用原特殊建筑造型，拆出可独立转动的轮盘和吊索摆锤。
- `art/BUILDING_DIRECTION.md`：用户选择的卡通方向、概念图来源和建模取舍。
- `art/README.md`：重新生成方法和模型坐标说明。
- `art/map-specials/`：海湾小镇与都会交通城的两张 ImageGen 概念板、完整提示词及实际 Blender 渲染。
- `art/build_map_specials.py`、`assets/models/compact-specials.glb`、`expansion-specials.glb`：按照概念板建立的两套独立特殊建筑，每套七种轮廓；对应 `.blend` 保留可编辑模型。经典地图继续使用原有特殊建筑。

## 验证

下列检查只需要 Node.js，无需安装其他依赖：

```powershell
node tools/economy-check.cjs
node tests/chance-presentation.test.cjs
node tests/check-ownership-frames.mjs
node tests/check-map-specials.mjs
node tests/check-chance-scene-trigger.mjs
```

分别覆盖真实开局与资金规则、奇遇金额和阅读时间、产权边界、真实 GLB 模型与动件、机会触发格反馈。模型检查使用仓库自带的 Three.js；它们不替代浏览器视觉检查。

`node tools/economy-simulation.cjs tools/economy-holdout.json` 可复现三地图经济与先后手对比，直接运行真实游戏规则并关闭画面与等待。对照旧版时从 Git 读取指定版本，并统一双方基础轮数。

独立种子共 45,000 局的结果与统计口径见 [经济与先后手复验](reports/economy-review.md)。最终同策略 AI 先手胜率约 56%，仍有残余优势；大环线低于 ¥400 的现金快照比例由 13.94% 降到 5.87%。
