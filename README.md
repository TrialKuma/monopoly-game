# 环城大富翁

一个支持手机竖屏的人机大富翁小游戏。掷骰子、买地、升级、抽卡，在五张地图里经营地产，把结束时的现金和收藏品带回仓库，再建设自己的小城。

## 本地运行

需要通过 HTTP 服务器打开；页面使用 ES module，直接双击 `index.html` 无法完整加载。

在本项目目录打开终端，安装有 Python 时运行：

```powershell
python -m http.server 8876
```

浏览器打开 [http://localhost:8876](http://localhost:8876)。停止服务器可在终端按 `Ctrl+C`。

## 开始游戏或观看演示

首页选择地图，点击“开始游戏”，确认门票后进入固定回合对局，不再选择破产淘汰模式。

| 地图 | 步位 | 回合上限 | 特点 |
| --- | ---: | ---: | --- |
| 经典环线 | 22 | 30 | 原有的均衡节奏 |
| 紧凑冲突 | 18 | 26 | 地产密集的短环，地价高、起点补给大，命运转盘可能引发地震 |
| 都市大环线 | 28 | 40 | 六街区连续单环，随机开业地产，建设与翻盘更充分 |
| 潮汐港湾 | 34 | 40 | 宽主岛三处大地产，每三栋地产穿插建设局、补给站或道具商店；外岛弧形环绕。红、黄航线各 35 步、各经过左右两岛，中央方向交替，70 步循环；逆行沿实际航程倒走 |
| 云岭温泉 | 24 | 30 | 山城环线，缆车随机前进 2–4 格、风车温泉与山泉晶石 |

- **回合制**：按所选地图的上限结算，现金最多者获胜。
- **历史淘汰局**：只保留旧记录的回看和兼容结算，当前没有新建入口。

| 地图 | 每人基础开局金 | 后手额外补给 | 经过起点补给 |
| --- | ---: | ---: | ---: |
| 经典环线 | ¥1,600 | 双骰卡 ×1 | ¥300 |
| 紧凑冲突 | ¥1,000 | 双骰卡 ×1 | ¥450 |
| 都市大环线 | ¥2,000 | 双骰卡 ×1 | ¥450 |
| 潮汐港湾 | ¥1,700 | 双骰卡 ×1 | ¥320 |
| 云岭温泉 | ¥1,900 | 双骰卡 ×1 | ¥350 |

首次仓库有 ¥1,200。入场支付门票：经典/紧凑 ¥100，都市 ¥200，港湾 ¥250，温泉 ¥350；点击出发前会显示扣款。局内现金只用来比输赢和记本机榜，不直接存回仓库。完成正式对局时按结果发仓库金币：以 ¥100 门票的地图为基准，胜利 300 加领先额的十分之一（封顶 300），平局 150，失利 50；门票更贵的地图按门票比例放大，例如温泉门票 ¥350，胜利基础 1,050、领先奖励封顶 1,050、失利 175。改版前的旧结算单仍按当时存回的现金计算。提前退出不退门票、不发结算收益。每局按完成、胜利、满级双格地产获得 1–3 件对应收藏品，金币加收藏品用于三级小城建设。本机榜按地图和模式分别记录结束现金，局外消费不改变成绩。仓库不足 ¥100 时，每个本机日期可领取一次 ¥300 救急补给。存档保存在当前浏览器。

竖屏主操作固定在屏幕下方，背包、双方资产对比、规则从底部打开，点选地块可查看详情；事件需要点右侧“继续”或确认按钮，不会倒计时自动跳过。返回首页也使用游戏内确认面板，右侧确认退出，左侧“继续本局”恢复当前回合及尚未完成的选择；移动和演出期间需等当前步骤完成。默认局部镜头带死区和平滑延迟跟随当前行动方：敌方回合跟随敌方，轮到玩家时缓动回玩家身上。手势按住时暂停位置跟随，松手后自动缓动继续，并保留调整后的角度和倍率。放大时会适当缩短跟随延迟，避免棋子走出画面。点“跟随”恢复默认角度和倍率，“全图”查看整张地图。

所有地图的后手补偿均为一张双骰卡，不再增加金币；玩家和 AI 遵循同一规则。硬币确定先后手后，卡牌一次性放入后手背包，自选时机使用，先手没有开局赠卡。回合推进以回到本局先手为一轮；休整、护盾与额外行动仍各按原规则结算。

首页的“玩法演示”进入所选地图的独立示例，用示例地产和资金展示收租、市政卡、护盾、救助、买地、升级及道具商店，不计入历史战绩。都市大环线还可体验冲刺路线。演示内每个按钮会重新设置示例局面。想实际游玩，请点击“开始正式对局”；正式对局中隐藏演示入口，避免误重置正在玩的游戏。

都市大环线的城市快线随机前进 3–5 格，沿当前行进方向移动，并继续结算落点。传送港随机跳到地产后，也会立即触发购买、升级或收租，因此仍可能间接进入温泉；传送不领取经过起点的奖励。护盾等原有规则照常生效。

紧凑冲突没有冲刺站、传送港和城建局，原来的三格改成地产，共 11 块地。买地价约为原来的 1.5 倍，建造费和租金不变；开局 ¥1,000，经过起点领 ¥450，经过起点不再自动建楼，道具商店不出售机车卡。命运转盘每次停留有一半概率地震，每局最多一次：最高的一到两栋楼先塌（同高随机），变成无主废墟，原等级保留；谁先停上去，花一半成本修好就归谁。没有地震时随机发生夏日祭（双方各领 ¥100）或金库赞助（金库加 ¥200）。

停留市政府时，随机获得一张买地卡或卖地卡，存入背包。先走到对手地产、正常结算落点租金，等下一个自己的正常回合开始，仍停在该地产时才可用卡。买地卡把地产转给使用者，使用者支付完整成本给原主；卖地卡强制地产出售给市政府，原主获得完整成本，地产变为无主。价格统一为地价加当前等级累计建造费，无溢价，建筑等级保留。被售出的已建地产再次购买也按完整成本出售，初始开业地产保留原有优惠。无落点结算的传送、回溯、换位不能绕过交易等待；额外行动不算下一正常回合。玩家与 AI 遵循相同规则。

银行存款会单独掷一次存款骰，点数 × 30 决定应存金额，最多扣除现有现金；这颗骰子不改变步数，也不触发掷六再动。满级收益地标把收入与“已满级”合在同一幕展示；救助金不会在下一次行动重复发放或播放到账演出。

温泉休整与冻结在同一次行动内消退，不会在休整时再次收租、重新延长住宿。休整结束后可正常移动；如果实际移动后又落到温泉另一半，仍按正常落点结算。

都市大环线每局在六个街区各随机选一处无主地产，提前建好 Lv.1 建筑；仍按原地价出售，买下即保留建筑。不同开业组合让每局有不同的热门地段。28 个步位首尾相连，顺行和逆行都会经过全图；当前棋子带步位编号和下一步箭头。地图标题下可展开“本图玩法”，查看地图特性与本局开业地段。

回合制中，每次无力付清租金时获得 ¥200 救助金。紧凑冲突另获一次过路护盾，下次行动正常掷骰，不再罚停；都市大环线也获一次过路护盾，但保留休整一回合。护盾只免交一笔租金，不免除实际踩入温泉的休息效果。经典地图保留原有救助和休整；破产淘汰制仍立即结束，不触发救助。

游戏页顶部可以分别开关音效和音乐。事件使用直接的行动结果、金额和归属说明，升级显示花费、等级与租金；去掉与操作无关的抒情旁白。事件等待玩家手动继续。演出响应系统的“减少动态效果”偏好；浏览器无法使用 WebGL 时会回退到原有棋盘。

原机会格改为道具商店，不再触发原来的随机机会事件；每次提供三张不同的道具卡，每次最多购买一张，也可离开。购买后存入背包，不立即使用；免费翻牌格仍保留。时光回溯售价 ¥160，选择自己或对手后退三格，不结算落点。AI 遵循同样价格，至少保留 150 金币，不重复囤积同种卡。过时回调、换局与重复点击不能重复扣款或发卡。

命定骰指定本次正常掷骰的 1–6 点，不再额外移动后再掷骰，与双骰效果互斥；指定六点不会触发随机单骰六点的额外行动。商店出售 ¥400 的机车卡，使用后本局持续拥有机车，可在掷骰前选择单骰或双骰，选择会保留到后续回合；两个骰子分别随机取点并相加。机车卡不进入免费翻牌池，拥有后不会重复出售。

五个地区各有七种建筑卡，共 35 张：经典、紧凑、都市、港湾、温泉。每张地图的正式对局结算都从本地区的七种里随机抽取三张，选择一张领取；港湾本局建设已赚到的额外卡仍自动入库。选项随本局记录固定，领取需要显式确认；未领取奖励会在刷新后恢复，已领取不会重复发放。尚未接入广告，也没有模拟广告领取全部的入口。建筑卡用于回城解锁建筑和合成升星；道具卡仅属于当前对局。

城镇统一使用原有三种素材开发土地和建设公共景观；建筑卡解锁房屋并合成升星。土地按顺序向外开放，扩建不移动或缩小已有建筑：

| 新区域 | 土地范围 | 新增 | 消耗 |
| --- | --- | --- | --- |
| 码头区 | 6×6 → 8×6 | 12 格 | 500 金币 + 2 海螺 |
| 花园区 | 8×6 → 8×8 | 16 格 | 800 金币 + 2 印章 |
| 新街区 | 8×8 → 10×8 | 16 格 | 1,200 金币 + 3 印章 |
| 观景区 | 10×8 → 10×10 | 20 格 | 1,600 金币 + 3 晶石 |

海岸花园、滨水码头、海角灯塔均直接显示在城镇岸边，各有三级外观。沿用原项目的素材、金币价格与已购等级，旧仓库里的 CSS 城镇及独立建设入口已移除。v4 存档保留全部旧账单、库存和建筑坐标；已付 800 金币扩成 8×8 的旧城镇视为前两区已开放。v5 存档在此基础上补齐另外四个地区的 28 张建筑卡，默认未收集，港湾进度和未领取的三选一原样保留。城镇只加载已摆放建筑和正在预览的建筑所属地区的模型包。新扩建和景观升级同时校验并扣除金币、素材，保存失败不扣款。

首页出发按钮直接标门票，点击后先保存扣款，成功才创建对局并进入地图。没有二次入场说明弹窗；再来一局和城镇出发都先回选图页。先手结果只显示行动方与后手补偿，日常弹窗保留结果、价格及卡牌效果，删去重复规则说明。独立预览 `town-review.html` 可逐区扩建、切换景观等级，不读写存档。

局内建筑真正升到 3 级时，屋顶播放三束金色及产权色烟花；回城合成三星也会在一栋已摆放的对应建筑上庆祝。初次载入、重复渲染、再次摆放和重开城镇不会误触发；减少动态效果时跳过，动画结束释放粒子资源。

购买与升级弹窗突出本次售价，基础租金为次要信息，不显示操作后余额；购买成功只显示地名和归属。点击已建建筑可“近看建筑”并旋转、缩放，只展示当前等级。空地和升级弹窗不提供未来等级预览，达到三级后才能近看满级模型。

整张棋盘也支持互动：按住棋盘拖动旋转，滚轮缩放；触屏可单指转动、双指缩放。右上角提供转向、缩放与回正按钮。日常状态刷新保持你的镜头，新局恢复默认取景；拖动松手不会误选地块，事件演出和建筑近看期间暂停棋盘手势。

已购地产用完整的圆角产权框围住整块土地，玩家为青绿、对手为橙红；双格地产只有一个连续外框。公共特殊地块也有独立配色的完整外框，例如银行金色、道具商店粉色、翻牌格紫色、传送港青色。选中或发生事件时另亮外侧轮廓，类别与产权颜色保持可辨。

建筑之间略加间距，所有步位增加编号落点垫，拐角留出更大的站位。棋子站在垫上，两人同格时并排站立，路线与建筑分开辨认。

漫画气泡集中在大额账单、现金见底、反超、护盾、救助和重要购买，普通小额租金、空地购买、常规收入及升级保持安静。喊话之间留有间隔，同类反应也有冷却，避免每个动作都要听两人拌嘴。买地仍播放开张庆祝，连成街区、购入大型地产或带楼入手时强化表现，徽标只展示实际购得的地产，费用仍按原价扣除。台词和粒子使用独立的表现序列，不参与掷骰或商品的随机抽取。

棋盘右上角的气候条可以展开，分别选择光照、季节和天气，并记住本机选择。光照包括清晨、白天、夕照、月夜和自然流转；清晨偏浅蓝冷白，夕照偏金黄。太阳与月光改变照射方向和建筑投影，天空、地面、环境光随之过渡，入夜逐渐亮起窗灯和路灯。暖色路灯会照到周围地面，雨雪天气会改变天光和阴影的对比度。这是为微缩城市设计的实时光照近似，不是路径追踪。

四季有各自的树色、地面色彩和环境粒子：春日花瓣、盛夏雨丝与涟漪、金秋落叶、冬日飘雪。积雪沿建筑实际屋顶形成薄层，持续飘雪约 8–10 秒逐渐积满，停雪后缓慢消融，雨水加快融雪；玻璃、水池和转动部件不被整块涂白。季节可自动轮换，天气也可单独选择晴朗、下雨或飘雪。所有变化只影响画面，不改变骰子、经济、事件概率或胜负。减少动态效果时保留静态积雪、季节与光照，隐藏页面时暂停环境动画。

棋盘外围有连续的岸线、绿植、路灯与社区。灯塔和风车沿用已有三视图，在 Blender 中重建规整轮廓和独立活动部件；中央庭院和外围景观单独组织，数字落点不被装饰占用。气候条内可关闭“周边小景”，选择会在本机保留。

植被使用分叉树干、成团叶簇、针叶枝束和林下地被。法式街区配几何花坛与修剪树，京都配樱树、竹林、石灯笼与枯山水，都市配树篦、花床与木条座椅；港湾增加缓慢水纹、浅海色层、岸边花草及系船设施，山城增加草坡、岩层和溪边植物。草地保留低对比色差，装饰合批以控制绘制开销。本轮没有重新生成 AI 素材。检查范围与竖屏截图见 [景观与回合更新记录](reports/landscape-v3-validation.md)。

中庭和外围空地进一步改成连贯的地形与水岸：法式阶地镜池、京都曲水苔丘、都市雨水花园、港湾沙洲潮池、山城溪流河湾。四角采用宽池湾、浅岸与低坡，成片地被沿岸布置，保持原树木数量。新增地形在棋子路径、地块表面和默认竖屏镜头下进行实际三角面净空检查；结果和五图截图见 [地形水系更新记录](reports/terrain-v4-validation.md)。

五张地图采用法式街区、京都町屋、纽约装饰艺术、地中海岸、阿尔卑斯山城五种建筑语言。正式建筑改为沿用已有三视图的 Blender 重建版本，以京都住宅样板的规整瓦片、梁柱、窗格和倒角为制作标准，覆盖 145 个可玩建筑、灯塔和风车，以及 25 个同设计远景。小住宅、商铺和公共建筑同样使用完整构件；升级通过楼层、体块、附楼和屋顶变化体现。正式资源、来源、几何统计与本轮检查结果以 [Blender 发布记录](art/blender-city/release.json) 为准。画面检查和资源预算分别记录，桌面浏览器的竖屏模拟不代表实测手机帧率。

近景的存储压缩保留顶点位置、三角拓扑和 ORM 贴图原字节；法线使用 16 位、范围内 UV 使用 16 位、顶点色通常使用 8 位，京都住宅二级样板保留 16 位颜色。这是误差受限的量化，并非无损压缩，逐资产误差与前后散列记录在 `art/blender-city/reports/storage-compression/`。所有正式预览都从最终压缩后的 GLB 重新读取渲染。远景另从同一设计制作较低面数版本，近景不为缩小下载包而减面。

打开 [建筑与三视图对照](http://localhost:8876/art-review.html)，默认查看游戏中的 Blender 模型和沿用的正、侧、背三张设计图；[整套建筑对照](http://localhost:8876/art-board.html) 可查看每张地图的全部 29 栋建筑，同一建筑族的三个等级使用相同镜头比例。版本选择中的“历史 AI 候选”只用于回看旧制作结果。历史 Pixal3D 推理、模型与验收记录保留在 [全量 AI 建筑档案](art/full-ai-city/README.md)，其中的旧批准记录不代表 Blender 版本的视觉验收，也不能覆盖用户后续对旧模型质量的否定。

中央喷泉的水流与涟漪、散步的小人、热气球和点状微光让城市保持生气；道具商店使用各地区卡牌亭，城建局吊索摆锤使用独立部件围绕真实轴心运动。

## 代码与美术入口

- `game.js`：地图、回合、资金、地产、卡牌和胜负规则。
- `scene.js`：Three.js 微缩城市、建筑模型、棋子、灯光与场景动画。
- `scene-life.js`：中央生活场景、特殊建筑活动部件、窗灯与环境模块的生命周期。
- `scene-lighting.js`：太阳/月光方向、真实投影、天空与地面渐变、天气影响和局部灯光。
- `scene-weather.js`：四季色彩、花瓣、落叶、雨雪及湿润环境效果。
- `scene-snow.js`：实际屋顶表面的积雪层、积累与融化。
- `scene-outskirts.js`：可开关的棋盘外沿岸小景。
- `scene-garden-kit.js` / `scene-regional-parks.js`：各地区外围与中央庭院。
- `scene-landscape-details.js`：草地表面、港湾水纹、岸线和山地细节。
- `scene-terrain-kit.js` / `scene-destination-terrain.js`：连续低坡、池湾岸线、港湾沙洲与山城河谷。
- `scene-streets.js`：地区铺装、倒角路缘和石砌沙盘基础。
- `art-review.html`：实际建筑与生成三视图的对照验收页。
- `art-board.html`：每图 29 件建筑的统一尺度对照。
- `art/blender-city/`：当前 Blender 重建脚本、三视图目录、编辑源与发布记录。
- `art/full-ai-city/`：历史逐件三视图、AI 生成证据、冻结审核图和旧发布流程；原始记录保持不变。
- `art/build_regional_city.py` / `art/regions/`：上一版制作脚本与历史来源；旧脚本不会覆盖正式地区模型。
- `scene-destinations.js`：港湾/温泉场景、正式 GLB 与部件动画、景观批处理。
- `progression.js`、`progression.css`：仓库、门票、收藏品、局外升级、本机榜与结算。
- `mobile.css`：竖屏视口、底部操作与信息抽屉。
- `presentation.js`：连接游戏状态与表现层，更新信息面板，组织事件演出和独立预览。
- `drama.js`：收租、征用、护盾等事件的画面、节奏与音效反馈。
- `index.html`、`presentation.css`：页面结构和新版界面样式；`styles.css` 保留原棋盘回退样式，`scene.css` 与 `drama.css` 分别配合城市和演出。

以下是早期 Blender 资产库的历史制作入口，部分公共景观和基础建模方法仍复用；本轮建筑的具体生成入口与参考图绑定见 `art/blender-city/`。早期基础库保留 20 个模型，第二轮增加 9 个分级地标与 8 个特殊地块模型。摩天楼使用真实增长的细长塔身和金色冠顶；金融中心是错落双塔；温泉庄园由多栋楼阁、汤池、瀑布、拱桥与庭院组成。特殊地块通过穹顶、圆形金库门、塔吊、巨牌、转盘和门架等不同轮廓识别。

模型包下载完成后分别显示，不必等全套到齐；新特殊建筑仅加载所选地图的一套，切图时再补另一套。已下载的公共模型复用缓存，网络失败时仍可操作棋盘，并可在近看时重试缺失建筑。

- `assets/models/city-kit.glb`：早期基础模型库，约 2.9 MB；本轮地区建筑按地区包加载。
- `assets/models/city-kit.blend`：可编辑的 Blender 模型库，含预览相机与灯光。
- `art/build_city_kit.py`：完整建模与导出脚本。
- `assets/models/landmarks.glb`、`landmarks.blend`：摩天楼、金融中心、温泉庄园的三级模型与可编辑源文件。
- `assets/models/specials.glb`、`specials.blend`：八种特殊地块与可编辑源文件。
- `art/build_landmarks.py`、`art/build_specials.py`：第二轮建模与导出脚本。
- `art/build_scene_life.py`、`assets/models/life-specials.glb`、`life-specials.blend`：沿用原特殊建筑造型，拆出可独立转动的轮盘和吊索摆锤。
- `art/BUILDING_DIRECTION.md`：用户选择的卡通方向、概念图来源和建模取舍。
- `art/README.md`：重新生成方法和模型坐标说明。
- `art/map-specials/`：海湾小镇与都会交通城的两张 ImageGen 概念板、完整提示词及实际 Blender 渲染。
- `art/build_map_specials.py`、`assets/models/compact-specials.glb`、`expansion-specials.glb`：按照概念板建立的两套独立特殊建筑，每套七种轮廓；对应 `.blend` 保留可编辑模型。这是当时的经典地图特殊建筑接入方案，本轮地区模型不再沿用这套来源。
- `art/harbor/`：历史灯塔和风车的 ImageGen 参考、推理证据及整理记录。`assets/models/harbor/` 为正式 Blender 主景包的安装位置，实际版本以 `art/blender-city/release.json` 为准。历史原始高面数输出与运行缓存仅保存在本机。
